# Chandu Sri — AI/ML Engineer Portfolio

A responsive, single-page portfolio adapted around the sidebar + tabbed-content structure of the reference portfolio, redesigned with a premium dark AI-engineering visual system.

## Stack
- Semantic HTML
- CSS custom properties, responsive grid/flex layouts, mobile breakpoints
- Vanilla JavaScript for navigation, project filters, contact email preparation, and footer year
- Google Fonts (Manrope + DM Mono)

No build step or framework is required.

## Run locally
Open `index.html` in a browser, or start a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the branch containing these files and the **/(root)** folder.
4. Save and wait for the deployment status to complete.

If this is hosted in the `chandusriii/chandusriii` profile repository, the project site URL may be `https://chandusriii.github.io/chandusriii/`. For the clean root URL `https://chandusriii.github.io/`, use a repository named `chandusriii.github.io`.
